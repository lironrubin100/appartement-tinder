# Development workflow

The repository-local delivery skill is the authoritative process document:

[`../.agents/skills/shutaf-development-workflow/SKILL.md`](../.agents/skills/shutaf-development-workflow/SKILL.md)

Use this page as the human entry point. It answers two questions before each change:

1. Is this the smallest system capability needed next (`foundation/`), or a user-visible outcome (`feat/`)?
2. Can this branch ship safely by itself?

If either answer is unclear, read the skill before starting work. Product and architecture answers always come from [`../DECISIONS.md`](../DECISIONS.md).
