# Shutaf coordination

Follow [AGENTS](../../../AGENTS.md), [START_NEXT_WORK](../../../docs/START_NEXT_WORK.md) and [EXECUTION_PROTOCOL](../../../docs/EXECUTION_PROTOCOL.md). Repository owner instructions govern authorization, checkout reuse and continuation; this skill adds no separate approval gate or worktree-per-outcome rule.

Plan mode reconciles ideas, decisions and atomic tasks in existing records; it does not implement product work. Build mode uses the selector card directly and does not load this coordination skill for ordinary tasks. Resume from the shared current index and one owning checkpoint. For a broad request, map outcome, source/evidence, bounded domains and overlap before implementation. Ask only about a concrete missing choice. Use focused read-only delegation only when authorized and useful; keep one writer for shared schema/contracts. Reuse current source and approved decisions. Consolidate findings into the smallest next useful outcome; do not create another planning/status taxonomy.

Use existing work cards, testing commands and records. Verify actual behavior and integrate one coherent change at a time under the standing owner authorization. Keep summaries short and distinguish implementation, acceptance, integration and deployment. A new worktree needs a concrete isolation reason and recovery/cleanup condition. No automatic subagents or extra checkouts for routine work.
